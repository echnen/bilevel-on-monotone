# Regularized extragradient method for structured bilevel optimization in continuous and discrete time. Example code

This repository contains the experimental source code to reproduce the numerical experiments in:

* R. I. Bot, E. Chenchene, D. Hulett. Regularized extragradient method for structured bilevel optimization in continuous and discrete time. 2026.

To reproduce the results of the numerical experiments run:
```bash
python3 main.py
```
